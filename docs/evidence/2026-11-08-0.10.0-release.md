local candidate Codex parsing/install, native Claude strict validators, all
repository gates, two reproducible builds, all 44 resource comparisons and
isolated wheel CLI behavior. Those observations identify their exact snapshot
in the preparation outputs; they do not substitute for final clean-commit checks.

Run the documented gate and build/package checks on the clean release commit;
tag only that validated commit and record artifact SHA-256 digests in the tag
and release assets. Verify tagged Codex/Claude marketplace installation,
OpenCode per-project package loading, uvx snapshots, remote identity and assets
after publication. Keep all check installations in disposable scopes.

installation/loading is separate from full model behavioral acceptance. Claude's
optional directory icon warning and Codex's temporary helper-alias warning remain
nonblocking; strict schema/install results must still pass. Ruff 0.17.3 and

upgrade is performed.

Publication and final channel evidence will be appended after observation;
