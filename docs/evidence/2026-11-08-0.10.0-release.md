local candidate Codex parsing/install, native Claude strict validators, all
repository gates, two reproducible builds, all 44 resource comparisons and
isolated wheel CLI behavior. Those observations identify their exact snapshot

and release assets. Verify tagged Codex/Claude marketplace installation,

nonblocking; strict schema/install results must still pass. Ruff 0.17.3 and

upgrade is performed.

Publication and final channel evidence will be appended after observation;

## Retained verification observations

The first package comparison caught CRLF worktree bytes differing from committed
LF in release UI metadata and the router body. Normalizing only those checkout
bytes to the existing Git blobs and refreshing Git's stat/index cache produced
no staged content changes; the release commit remained identical. Both artifacts
were rebuilt and all byte comparisons passed before tagging. This is why the
final artifact digests differ from the prepare-only preview outputs.

OpenCode's `/doc` returned the web UI, so the check used native `plugin.list`
and `skill.list` operations. Early transient/initial queries had empty registries
before asynchronous package initialization. A persistent hidden loopback server
needed its generated local password; no authentication policy was changed and
no password is included in this record. After initialization, actual active
package/skill assertions passed. The first verification script used Windows'
legacy text encoding; the explicit UTF-8 rerun passed without a product change.
The owned persistent server was stopped after verification. No paid model
inference was needed for installation/loading proof.
