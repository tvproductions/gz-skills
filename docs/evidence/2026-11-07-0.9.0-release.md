# Bundle 0.9.0 release evidence

The maintainer authorized preparation, publication and verification of 0.9.0
on November 7, 2026. The bundle remains in 0.x development; the next minor is
0.10.0. This release does not propagate updates into existing consumers.

## Scope and policy review

Base: published v0.8.3 at `d6acc26e28ca1c4f43e5bb46d8973021d7d006c3`.
The coherent minor bundles Python policy ownership corrections and this
publisher's independently selected Python 3.14 environment:

| Component | Released | 0.9.0 | Classification and impact |
| --- | --- | --- | --- |
| Bundle / Python CLI | 0.8.3 | 0.9.0 | Changed support contract: `>=3.13` becomes `>=3.14,<3.15`; use Python 3.14 for snapshot CLI installation. Native skill plugins do not need this CLI. |
| gzs-project-setup | 0.3.1 | 0.4.0 | Remove library-owned Python/tool/package defaults; resolve consumer authority and leave missing authority unresolved. |
| gzs-update-dependencies | 0.3.0 | 0.4.0 | Same authority correction; preserve approved consumer choices and exceptions. |

Other skill trees are unchanged from v0.8.3. The standalone setup helper keeps
its existing Python 3.11+ compatibility and narrow settings schema. No dependency
or packaging-backend migration is included. Existing consumers review their own
adopted policy before explicitly selecting this release.

Reviewed the canonical starter at
`a483e382146c6082e590e31494c07d1812645014`: `docs/versioning.md`,
`docs/baseline-policy.md`, `docs/engineering/python.md`, and `CHANGELOG.md`.
This is the same immutable authority reconciled in the Python correction
receipt. Its current development guidance includes minimum-only uv and the
portable-policy ownership correction; those remain unreleased in the starter.
Adopt the shared SemVer/coherent-minor rules and this repository's explicit
Python-family binding. Preserve separation from formal template adoption and
from unrelated consumers' policies. No new policy exception is taken; this
does not certify full starter/Astral conformance or unfinished ecosystem work.

## Preparation observations

Actual tools: managed Python 3.14.10, uv 0.13.6, Codex CLI 0.167.0,
Claude Code 2.1.319, OpenCode 2.2.0. CPython's authoritative stable `v3.14.*`
tag inventory still ends at 3.14.10 at review time.

Preceding immutable v0.8.3 HTTPS marketplace installations passed in separate
disposable Codex and Claude configuration directories. Candidate Codex native
manifest parsing and local installation passed using a disposable local
marketplace containing copies of the canonical manifest and skill trees.
The actual candidate Git marketplace entry was separately parsed by Codex;
its HTTPS tagged installation must be verified after publication.

Claude strict plugin and marketplace validation pass. Its optional public
directory checks report `ICON_MISSING`, outside the strict marketplace result;
universal directory submission is not part of this release.

The first ty command incorrectly supplied pyproject.toml to `--config-file`,
which accepts only ty.toml. The corrected `uvx ty check --project .` passes.
An initial disposable Codex local-source fixture used an absolute path and was
skipped; the documented relative path fixture installed successfully. Neither
fixture required a product change or validation bypass.

## Final release verification

The GitHub release and immutable annotated tag record the exact clean release
commit and artifact SHA-256 digests. Required clean-commit checks, package
content inspection, and tagged-install results are recorded there after
execution. This repository has no configured hosted quality CI; local gates
are distinct from unavailable exact-commit hosted evidence. No consumer locks,
